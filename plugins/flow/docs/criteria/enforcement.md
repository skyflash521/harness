# 守らせる機構の規約

エージェントが従うべき定めを新設・変更するとき、**機構が要るか、要るならどの機構が保証するかの
正本**とする。プラグインが配布する定めにも、リポジトリが自分で置く定めにも当てる。既存の定めの
言い換え・参照の追随は対象外。

## 1. 機構が要るかは、破ったときの悪影響で決める

**破ったときの悪影響が無い、またはごく軽微で復旧できるなら、
守らせる機構は要らない。** 機構が要るのは、破った結果が次のいずれかに当たるときである。

- **取り消せない。** 外部への公開・配信・プッシュ、追跡外ファイルの破棄、履歴の書き換え。
- **成果物に残り、後から読む者を誤らせる。** 混入した記述、正本どうしの食い違い、裏取りの無い数値。
- **判定を偽る。** 収束していないものを収束として扱う、確かめていないものを確かめたとして扱う。
- **ユーザーが手を入れるまで作業が進まない。** 止まるべきでない所で止まる、背景処理を待たずに手番を返す。

いずれにも当たらない規律——手順の順序や道具の選び方のように、抜かしても取り直せば済むもの——は
機構を持たなくてよい。読まれたときにだけ効く層——指針文書・スキル文書・エージェント定義——へ書く。
**機構が要らないことは、守らなくてよいことではない。**

## 2. 機構が要る規律を、読まれることだけに依存させない

指針文書に置いた規約も、スキル文書・エージェント定義に書いた定めも、当人が読むかどうかに
依存する。機構が要ると判断した規律を、この層だけで
完結させない。守らせ方は次のどちらかである。

- **機械**: フック・契約スクリプト・検査スクリプト・CI。ツール呼び出しとターン終了を起点に弾く。
- **他エージェント**: レビューが毎ラウンド照合する規約の正本へ節として置き、その節が毎ラウンド
  読まれる状態にする。

どちらも当てられないなら、その規律を足さずに止めてユーザーに諮る。

## 3. 機械を先に検討する

**フックが最善**、次が検査スクリプトと CI、**レビューは次善**——依頼文へ観点を載せる工程を踏まない
経路には届かない。

上位の手段を採らないと決めてよいのは、[§4](#4-経路ではなく発火を確かめる)の確認で、上位の機構の
起点が無いか、起点は在っても違反を判定しきれないと分かったとき、または
[§5](#5-機構を過剰に作らない)に当たるものしか作れないと分かったときに限る。手間の大小で決めない。

## 4. 経路ではなく発火を確かめる

参照経路が在ることは強制ではない。**その規律が問う場面で、その機構が起動するか**を確かめる。

- 起点の無い失敗には、まず起点を作れないかを見る。ツールを呼ばずにターンを終える失敗は、ツール
  呼び出しを起点とする機構には掛からない。
- レビューへ載せるなら、その規律が問う対象が差分に現れることを確かめる。着手しなかった作業や、
  止まらずに進んだ判断は、レビュアーの入力に無い。

**自由な自然言語の照合を、規律の保証に数えない。** 見る対象がユーザーの発話・エージェントの
出力・文書の地の文であるとき、語・言い回し・正規表現を列挙して当てる作りは、違反を判定しきれない。
同じことを表す言い回しに限りが無く、**列挙は必ず取りこぼす**。その機構が在ることをもって、
[§2](#2-機構が要る規律を読まれることだけに依存させない)が求める守らせ方が満たされたとしない。
**同じ理由で、列挙に無いものを弾く形(許可リスト)にもしない**——言い回しが違うだけの正当な入力が
止まる。

取りこぼすと承知のうえで、明らかな違反だけを先に弾く補助として置くことは、本節が妨げるものでは
ない(作るかどうかは[§5](#5-機構を過剰に作らない)が決める)。

**この禁止が掛かるのは、照合の相手が自由な自然言語であるときに限る。** 現れうる文字列の集合をこちらが
定義しきれるなら——機構が文言を指定して出させる、有限の選択肢から選ばせる、機械が生む定型
(シェルが渡す語・コマンド片)を見る——取りこぼしが残らないので、許可リストの形を採ってよい。

保証を担う機械が要るなら、自然言語ではなく**機械が生む構造**——ツール名・引数・終了コード・
ファイルの状態・差分——を見せる。それで判定できないなら、[§3](#3-機械を先に検討する)に従って
下位の手段へ降りるか、その規律を足さずに諮る。

## 5. 機構を過剰に作らない

**機構は守らせるための道具であって成果物ではない。** 次のものは作らない。

- 既存の機構が見ている場面へ重ねたもの。
- 確認のための機械の足場を日々の作業へ挟むもの(本体を包むラッパー、その記録と照合)。
- 防ぐ失敗の重さに見合わない作り込み(判定の網羅、作りの洗練)。見るのは出来上がった機構の
  作り込みであって、作るのに掛かる手間ではない。

これに当たるものしか作れないなら、下位の手段へ降りるか、その規律を足さずに諮る。
